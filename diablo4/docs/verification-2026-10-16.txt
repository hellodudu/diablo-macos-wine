## 1. 系统版本（条件 A 的排查）

`vercheck64.exe` —— 用于否定「Windows 版本不够」这个猜测。

```
指针宽度: 8 字节 (64 位进程)
GetVersionEx:        6.2 build 9200
RtlGetVersion:       10.0 build 19045  <- 内核真正用的值
PROCESSOR_ARCH:      AMD64

结论: 满足 Battle.net 要求（Win10+，Battle.net 要求 10.0+）
```

**要点**：注册表 `HKLM\Software\Microsoft\Windows NT\CurrentVersion\CurrentVersion`
一直是 `6.3`，但**应用不读它**。`GetVersionEx` 的 `6.2` 是 Wine 对无 manifest 程序的既定行为，也不是问题。

## 6. 环境变量 `WINEMSYNC` 的对照实验

| 配置 | 结果 |
|---|---|
| 基线（不设） | ✅ rc=0，D3D12 FL 12_1 |
| 加 `CX_ACTIVE_GRAPHICS_BACKEND` / `CX_GRAPHICS_BACKEND` | ✅ rc=0，D3D12 FL 12_1 |
| **加 `WINEMSYNC=1`** | ❌ **rc=1，无任何输出** |
| 全加（含 `WINEMSYNC`） | ❌ rc=1 |

结论：本机引擎上**不要**设 `WINEMSYNC`。
